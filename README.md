
# FilmMoods (movies‑only, free, no APIs)
A clean, high‑contrast, client‑side movie recommender driven by a 6‑D mood vector:
**happy, calm, inspired, intense, cozy, melancholic**.

## Use
- Drag sliders or type a prompt (e.g., `cozy romance`, `noir heist`, `epic war`, `feelgood`) and **press Enter**.
- Results reorder instantly using cosine similarity.

## Dev
```
npm install
npm run dev
```
